Where to point

A PEC run wants a field near the celestial equator, one to two hours east of the meridian, so the mount stays on one pier side for an hour without a flip. TheSkyX's Find box only takes names, so this page names a bright star that is in that window right now. Type the name into Find, press Slew, then in PHD2 pick any guide star in the field (not the bright one if it saturates).
