Where to point

A PEC run wants a field near the celestial equator, one to two hours east of the meridian, so the mount stays on one pier side for an hour without a flip. This page names a bright star that is in that window right now. Slew to it with the button below (it goes through NINA, after a confirmation, and is the only mount command pec ever sends), or type the name into TheSkyX's Find box and press Slew there. Then in PHD2 pick any guide star in the field (not the bright one if it saturates).

Slew the mount to

The mount will move. Go on only if the roof is open, the mount is homed and tracking, and nothing is between the telescope and the sky. pec checks the mount, roof and safety devices NINA has connected before it sends anything, but it cannot see what NINA cannot. This is the one mount command pec sends; the slew takes a minute or two and this dialog waits for it.
